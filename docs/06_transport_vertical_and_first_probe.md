# Desk Research — Round 6: Transport/Logistics Vertical + First Probe (2026-07-15)

Chosen world: **Industrial / logistics / transport.** Strategy: **distribution-first** (own the audience, monetize later).

## Tooling landscape (served — but that's fine for distribution-first)
- Small manufacturers: **Monitor ERP dominates (46% share)**; Novotek/Multisoft/GMDH for planning.
- Equipment rental: **Infobric Hyrma** dominant.
- Haulier compliance: tacho/kör-vilotider tools (FleetX, Tacho Online, Webfleet); lastbilscentraler intermediate admin.
We are NOT hunting tooling whitespace, so incumbents don't block us.

## Distribution feasibility — the key positive
Swedish transport/logistics has a dense, content-hungry ecosystem we can reach cheaply:
- Trade media: Transportnytt, Tidningen PROFFS, Svensk Åkeritidning, TransportochLogistik.se, Transportarbetaren.
- Orgs/communities: Sveriges Åkeriföretag, Transportföretagen; active Facebook groups; LinkedIn logistics.
- Clear high-intent Swedish SEO surface (calculators, guides, compliance how-tos).
**Verdict: best distribution feasibility of any vertical we've examined.** This is where Måns's edge actually applies.

## One honest tooling gap
"Too big for Excel, too small for Monitor ERP" — small manufacturers in the middle band lack fit-for-purpose planning/quoting. Recognized but unmet. Parking this as a possible later monetization hook.

## The pivot: from hunting to building
We've now done enough desk research. Distribution-first strategies are validated by *shipping a probe*, not more searching. The next step is to build a small Swedish-language distribution asset in transport and measure whether we can capture attention cheaply. If yes → the moat is real and monetization follows. If no → we learned it in weeks for ~€0.

## First probe candidates (free SEO tool/content that ranks, captures audience)
1. **Free calculator for a high-intent query** — e.g., kör- och vilotider planner, transport-/fraktkostnadskalkyl, åkeri-lönsamhet/timkostnad. Free tools rank well, cheap to vibe-code, capture email.
2. **Definitive Swedish guide hub** on a painful, evergreen transport-admin topic (ranks, builds authority, email capture).
3. **A niche newsletter/audience** for small åkerier/transport owners, seeded via the FB groups + SEO.

## Success metric for the probe (no phone)
Cheap organic traffic + email signups within a few weeks. That single test tells us if the distribution moat is real before building any product.

## Next step
Pick a probe angle → build it → publish → measure. Move from research to action.
